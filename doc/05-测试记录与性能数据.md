## 4. 测距优化前后对比（同一组 13 目标）

| 方案 | 单帧测距耗时 | 测距帧率 |
|---|---|---|
| 全宽横带 + 4 线程（初版，OpenCV 内部默认 8 线程造成超订） | 770 ms | 1.2–1.9 fps |
| 窄 ROI（框宽 + 视差范围）+ 6 线程 + OpenCV 单线程 | **44 ms** | **14.0 fps** |

优化要点：把 ROI 从“整幅宽度”缩到“目标宽度 + 视差范围”，并把 OpenCV 内部线程数
压到 1，避免 6×8 线程互相抢核（超订时反而慢一个数量级）。

## 7. 双目标定实测（棋盘格 9x6 内角点，格长按 25mm）

远程辅助流程：取景器全屏实时显示棋盘检出状态并自动存图 → 稳健解算（统一 SB 角点检测 +
逐视角误差剔除）→ 极线对齐自检。

| 指标 | 数值 |
|---|---|
| 采集图像对 | 58 对（其中 2 对 SB 检测失败被自动跳过） |
| 参与解算视角 | 56 |
| 单目 RMS | 左 0.239 px / 右 0.233 px |
| **双目 RMS** | **0.412 px** |
| 基线 | 65.23 mm（T = [-65.23, -0.15, 0.59]，y/z 分量≈0，符合水平双目） |
| 左目 fx/fy/cx/cy | 859.3 / 859.0 / 609.8 / 492.5 px |
| 右目 fx/fy/cx/cy | 864.1 / 863.6 / 678.4 / 489.8 px |
| 校正后 fx | 956.02 px |
| 距离公式 | `Z[m] = 62.36 / 视差[px]` |
| 极线对齐误差 | 平均 0.266 px，最大 1.51 px（校正正确） |

由该标定推算，采集时棋盘格距相机约 0.25–0.53 m（手持距离，合理）。

> **尺度提醒**：`Z ∝ 棋盘格真实边长`。上表按 25mm 格长计算；若实际格长不同，
> 用 `真实格长 = 25mm × 实测距离 / app 显示距离` 修正后重跑
> `eye_range_calib calibrate --square <真实格长>` 即可（不需要重新采集图像）。

## 9. 绝对测距精度实测（2026-10-13，46cm）与视差范围修正

现场条件：9x6 内角点标定板、格长 25mm，**卷尺实测板到相机约 460mm**，板子固定不动。
测量方式：从 `/dev/video0` 抓原始 2560x960 帧（每目 1280x960），在主控机上用
`config/calib.yaml` 复现应用链路（`initUndistortRectifyMap` 校正 → 棋盘/窄带 ROI 匹配 → 中值视差 → `Z = fx·B/d`）。

### 9.1 实测结果

| 方法 | 数值 | 对比 460mm |
|---|---|---|
| 校正后角点视差（6 帧） | d = 135.88–135.93 px（σ≈0.05mm） | — |
| **双目公式 Z = 62.36/d** | **458.8–458.9 mm** | **−1.1 mm（−0.24%）** |
| PnP 几何反推（独立于基线，左目校正图） | 垂距 464.4 mm，重投影 RMS 0.161 px | +4.4 mm（板中心偏心 142mm，欧氏距离偏大） |
| 角点间距反推 | dx→462 mm、dy→457 mm | <1% |
| 应用 ROI+SGBM 链路（`num_disparities=192`） | d = 135.75 px → 459.4 mm | +0.6 mm（+0.13%） |

`num_disparities` 改成 192 后原地回归（板子未动，4 帧）：角点法 459.4–459.7 mm，
应用链路 459.8–462.2 mm（均值 460.6 mm）。

### 9.2 近距视差范围（本次改动的原因）

`Z = 62.36/d` 决定了 `num_disparities` 就是最近可测距离的硬上限：

| num_disparities | 最近可测距离 |
|---|---|
| 128（改动前） | 487 mm |
| **192（当前）** | **325 mm** |
| 256 | 244 mm |

46cm 处真实视差已到约 136px，**超出 128px 上限**，SGBM 只能给出错误匹配：
按旧配置（128）实测 `d=31.2px → 2000mm`；改成 192 后同一帧 `d=135.75px → 459.4mm`。
目标框宽 ≤ ~480px（ROI 宽度 ≤ `max_roi_side`）时不会内部降采样，因此这个上限是硬约束。

离线图对（`testdata/`，13 目标）A/B 也印证：`num_disparities=128` 时多个目标视差被截断在
128px 内、匹配到错误位置（如 person 报 2.95m），192 下同一批目标视差升到 130–160px、距离回到
0.54–0.65m。

| 指标（同一图对，13 目标） | nd=128 | nd=192 |
|---|---|---|
| 测距帧率 | 13.0–13.8 fps | 10.7–11.6 fps |
| 单帧测距耗时 | 51–65 ms | 65–78 ms |

代价约 20–25% 测距耗时；实拍 30fps 场景下测距（~30fps，无目标时）不受影响。

### 9.3 待关注的次要观察

- 在本板所在的画面位置（偏右上），校正后左右目对应点**竖直残差中值约 2.5px**，
  板内视差 P10–P90 跨度 3.6px（≈±6mm@46cm）。第 7 节的极线自检平均误差是 0.266px，
  说明**偏离画面中心处的整流残差明显更大**。它没有影响中值精度（正好对上卷尺），
