## 2. 数据流

```
FrameBundle{left,right,timestamp,seq}
        │ 采集线程：imdecode → 按中点切分 → clone
        ▼
   LatestSlot<FrameBundle>          （覆盖式最新帧槽）
        │
        ▼ 识别线程
   letterbox(640x640,RGB,114 填充) → rknn_inputs_set → rknn_run →
   rknn_outputs_get(量化) → DFL 解码 → NMS → 原图坐标
        ▼
   LatestSlot<DetectBundle>{left,right,detections}
        │
        ▼ 测距线程
   目标级并行池 ──► 每个框：ROI 裁剪 →（可选）校正 → SGBM → 视差中值 → Z=fx·B/d
   IoU 轨迹关联 + EMA/滑窗平滑 → 全图视差/深度伪彩图（每 N 帧）
        ▼
   ResultFrame{annotated_bgr, disparity_vis, depth_vis, detections, ...}
        │
        ├── Qt 界面（QTimer 33ms 拉取显示）
        └── headless（打印统计 + 定时存图 + stats.jsonl）
```

## 3. 关键实现细节

### 3.1 预处理与官方实现对齐

`rknn_model_zoo` 的 letterbox 对缩放尺寸做了 `%4` / `%2` 对齐，且在 640x640 画布上
居中填 114。本项目逐行对齐该逻辑，保证框坐标映射回原图后与官方一致。

### 3.2 量化输出解码

- 模型输出 9 个张量：`[1,64,H,W]`（DFL）、`[1,80,H,W]`（类别）、`[1,1,H,W]`（类别和）。
- 三个尺度分别解码；先用类别和做快速过滤，再做 DFL 期望，最后按类别做 NMS。
- 阈值在量化域比较（`thres_i8 = conf/scale + zp`），省掉逐元素反量化。

### 3.3 视差与距离

- `rotate/缩放`：ROI 内部若降采样，视差按 `d_full = d_roi / scale` 折算回全分辨率。
- 距离 `Z = fx * baseline_mm / (d - doffs) / 1000`（米）。
- 有效点不足 24 个时判为无效，界面显示 `--m`，并在 `note` 里说明原因。

### 3.4 标定

- `config/calib.yaml` 由 `eye_range_calib` 生成（含 `M1/D1/M2/D2/R/T/R1/R2/P1/P2/Q`）。
- 缺少 `R1/P1` 时用 `cv::stereoRectify` 现场补算；标定尺寸与运行尺寸不同时按比例缩放内参。
- 没有标定文件也能跑：用 `fallback_fx`（默认 `0.85*单目宽`）与 `fallback_baseline_mm`（默认 60mm）
  估算，界面 HUD 打上「未标定/估算」标记，距离只能当参考。

## 4. 配置项速查（`config/eye_range.yaml`）

| 段 | 关键项 | 说明 |
|---|---|---|
| `capture` | `device/width/height/fps/swap_eyes` | `width` 是左右拼接总宽 |
| `detect` | `model/labels/conf/nms/npu_core` | `npu_core`: -1=AUTO, 0/1/2, -2=三核 |
| `stereo` | `num_disparities` | 16 的倍数；越大最近可测距离越近、越慢 |
| | `roi_only/roi_margin/band_max_height/max_roi_side` | ROI 匹配的形状与限幅 |
| | `threads/opencv_threads` | 目标级并行线程数 / OpenCV 内部线程数 |
| | `display_scale/display_num_disparities` | 界面伪彩图的降采样与视差范围 |
| | `fallback_fx/fallback_baseline_mm` | 未标定时的兜底内参 |
| `ui` | `fullscreen/show_depth/window_*` | 界面行为 |

## 5. 命令行速查

```
eye_range [--config cfg.yaml] [--device /dev/video0] [--size 2560x960] [--fps 30]
          [--model model/yolov8.rknn] [--labels model/coco_80_labels_list.txt]
          [--calib config/calib.yaml] [--conf 0.35] [--nms 0.45]
          [--npu-core auto|0|1|2|all] [--roi 0|1] [--stereo-threads N]
          [--image-pair left.png right.png]
          [--headless] [--duration 15] [--out-dir out] [--save-interval 2]
          [--log-level debug|info|warn|error]
```

`--image-pair` 用于没有相机时自测（不打开相机，循环处理固定左右图）。
