## 2. sysroot 策略（关键决定）

目标机上已经有**完整 OpenCV 4.5.4**，所以不需要自己编 OpenCV：

> 从开发板把 OpenCV 的头文件 / 共享库 / CMake 配置 / **依赖闭包**同步到本机
> `build/sysroot`，用它当交叉编译的 sysroot。这样“编译期看到的 ABI”和
> “板上运行时的 ABI”完全一致，板上也无需再传 OpenCV。

`scripts/bootstrap_sysroot.sh` 做三件事：

1. 用工具链自带的 libc sysroot 打底（`cp -a`，提供 libc/内核头文件、crt）；
2. 在板上（`scripts/remote_pack_sysroot.sh`）整理出规范化暂存树：
   - `/usr/include/opencv4`、`cmake/opencv4`、`pkgconfig/opencv4.pc`
   - `libopencv_*.so*`（162 个）
   - **`ldd` 依赖闭包**（319 个）：libjpeg / libpng / libtiff / openjpeg / protobuf 等
   - 板上 `/lib` 是 `/usr/lib` 的符号链接，`ldd` 会混用两种路径；
     脚本统一复制到 `usr/lib/aarch64-linux-gnu/`，并**同时复制符号链接与真实文件**，
     否则链接器按 SONAME 找不到库。
   - 排除 `libc/libstdc++/libgcc/ld-linux`：沿用工具链自带版本，
     编译产物就不会绑定比目标机更新的 glibc 符号。
3. 下载 tarball 解包进 `build/sysroot`。

## 3. Qt 的处理

板上没有 Qt 开发头文件，只有运行时 5.15.3 + xcb 插件。做法：

- **编译期**用本机 `/opt/qt5-arm`（5.15.2）的头文件与库；
- **运行期**由板上的 5.15.3 提供（Qt 同一 minor 系列二进制兼容，实测可用）；
- 因此部署包里**不需要带 Qt**，也不要把 `/opt/qt5-arm/lib` 传到板上（避免插件版本冲突）。

## 4. 工具链文件要点

`cmake/toolchains/aarch64-linux-gnu.cmake`：

```cmake
set(CMAKE_SYSROOT "${EYE_SYSROOT}")                 # build/sysroot
set(CMAKE_FIND_ROOT_PATH "${EYE_SYSROOT}" "${EYE_QT_ROOT}")
set(CMAKE_FIND_ROOT_PATH_MODE_PROGRAM NEVER)        # 程序仍用本机的
set(CMAKE_FIND_ROOT_PATH_MODE_LIBRARY BOTH)         # 允许找到 /opt/qt5-arm
```

`CMakeLists.txt` 里补了一条**必要**的链接选项：

```cmake
add_link_options(-Wl,--allow-shlib-undefined)
```

原因：交叉链接时，目标机 OpenCV 的传递依赖（libpng/libjpeg/libtiff/protobuf）
不会自动参与解析，链接器会报一堆 `undefined reference to png_*`。
这些符号在板上运行时由系统库提供，因此放行共享库的未定义符号即可。

## 5. 构建

```bash
scripts/bootstrap_sysroot.sh     # 只需一次（换板子/换 OpenCV 后重跑）
scripts/build_aarch64.sh         # 产物在 build/aarch64
```

产物：

| 文件 | 说明 |
|---|---|
| `eye_range` | 主程序（Qt 界面；`--headless` 无界面） |
| `eye_range_calib` | 双目标定（采集 + 解算） |
| `eye_range_sysinfo` | 环境自检（版本、相机能力、NPU、模型信息） |

## 6. 板卡通信

本机 WSL 没有 sshpass，`scripts/board.py` 用 paramiko 实现：

```bash
python3 scripts/board.py run "<命令>"
python3 scripts/board.py put <本机路径> <板上路径>      # 支持目录递归
python3 scripts/board.py get <板上路径> <本机路径>
```

连接参数集中在 `scripts/board_env.sh`（默认 192.168.228.113 / orangepi）。
