# 04 部署与运行手册

## 1. 一次性准备

```bash
cd /home/peng/eye_range
scripts/bootstrap_sysroot.sh      # 从板上同步 OpenCV 到 build/sysroot（首次/换板后）
```

## 2. 编译 + 部署

```bash
scripts/build_aarch64.sh          # 交叉编译到 build/aarch64
scripts/deploy_board.sh           # 打包 build/bundle 并上传到板
```

板上目录：`/home/orangepi/eye_range/{bin,model,config}`。
部署包**只带自研可执行文件 + 模型 + 配置**，OpenCV/Qt/RKNN 运行时都用板上的。

## 3. 运行

```bash
scripts/run_board.sh sysinfo                 # 环境自检（版本/相机/NPU/模型）
scripts/run_board.sh headless 15             # 无界面跑 15 秒，存图到 out/
scripts/run_board.sh ui                      # 启动 Qt 界面（显示在 HDMI 显示器上）
scripts/run_board.sh calib-capture           # 采集标定图像（放到棋盘自动存）
scripts/run_board.sh calib-solve             # 解算标定 → config/calib.yaml
scripts/run_board.sh raw "<命令>"            # 在部署目录直接执行
```

界面启动后：

- **默认铺满屏幕**：用无边框窗口覆盖可用区域（`ui.borderless: 1`）。
  `F11` 在「铺满 / 窗口」之间切换，`Esc` 回到窗口。
  命令行 `--borderless` / `--windowed` 可覆盖配置。
- 左侧：实时画面，检测框上标注 `类别 置信度 距离m #轨迹号`，`--m` 表示该目标视差无效。
- 右上：视差伪彩图；右下：深度伪彩图（0–30m）。
- 参数区：置信度 / NMS / NPU 核 / ROI 模式 / 测距线程 / 视差范围 / 块大小，均可边跑边调。
- 「保存快照」会把当前标注图与视差图写到 `snapshots/`。
- 「全屏切换」用于现场演示。

> **不要用 `--fullscreen`（真正的 EWMH 全屏）**：这块板的 X 没有可用 GL 驱动
> （`libGL: failed to load driver: rockchip`），xfwm4 合成器在 EWMH 全屏下做整屏
> 软件重绘会触发显示驱动致命错误，**几秒到几十秒后整机硬重启**（详见 `doc/06` 第 8 节）。
> 需要真全屏就先关合成器：`./board_display_check.sh fix`（可 `restore` 恢复）。
> 默认的无边框铺满模式在合成器开启时实测稳定。
>
> 无边框窗口按 `availableGeometry()` 摆放，顶部会被 xfce4 面板占掉约 31px。
> 想让它彻底占满，可以把面板设为自动隐藏（面板右键 → 面板 → 面板首选项），
> 或用命令行：`xfconf-query -c xfce4-panel -p /panels/panel-1/autohide-behavior -s 1`。
- 界面刷新率默认 20fps（`ui.fps`），视频缩放默认最近邻（`ui.smooth_scale: 0`）：
  板上是纯软件渲染，这两项直接决定 CPU 峰值。
- 供电/散热余量紧张时用低功耗预设：`./bin/eye_range --low-power`
  （NPU 单核 / 2 测距线程 / 15fps 采集 / 12fps 界面）。

> 板子在跑 X（lightdm），从 SSH 启动界面需要 `DISPLAY=:0 XAUTHORITY=/home/orangepi/.Xauthority`，
> 这些已经在 `run_board.sh ui` 里设置好。

## 4. 标定流程（把估算距离变成真实距离）

1. 准备棋盘格（默认 9x6 内角点、格长 25mm）。**格长务必量准**：距离与格长成正比。
   不知道棋盘规格时先跑 `eye_range_calib probe` 自动试出内角点数。
2. **采集（推荐用取景器）**：

   ```bash
   scripts/run_board.sh raw "cd /home/orangepi/eye_range && DISPLAY=:0 XAUTHORITY=/home/orangepi/.Xauthority ./bin/eye_range_calib capture --gui --out-dir calib_images --count 20"
   ```

   板子显示器上会全屏显示：`saved N/20  L=OK R=OK board=xx%`，并给出拒收原因
   （`board too small / too close / eyes mismatch / disparity odd / blurry - hold still /
   same pose - move board`）。照着提示把棋盘放到画面不同区域、不同距离和倾角，
   每次存图会有绿框闪烁反馈；`空格`手动保存，`Q` 结束。
3. **解算**：

   ```bash
   scripts/run_board.sh calib-solve      # 自动逐视角误差分析 + 剔除离群 + 解算
   ```

   会打印每轮 RMS、使用的视角数、基线、`Z = k / 视差`，并把结果写入 `config/calib.yaml`。
   双目 RMS 应 < 0.5px，否则检查采集质量。
4. **自检**（可选但推荐）：

   ```bash
   scripts/run_board.sh raw "cd /home/orangepi/eye_range && python3 board_calib_verify.py config/calib.yaml calib_images 9 6"
   ```

   打印极线对齐误差（应 < 0.5px）与标定板当时距离，用来判断格长假设是否合理。
5. 取回标定文件存档：
   `python3 scripts/board.py get /home/orangepi/eye_range/config/calib.yaml config/calib.yaml`
6. 重启 `scripts/run_board.sh ui`，状态区「标定」显示“已加载”，HUD 不再有「未标定/估算」标记。

判断标定质量：双目标定 RMS 建议 < 0.5px；baseline 应与实际镜头间距接近。

> 尺度核对：把物体放在卷尺量好的 1.00m 处，看界面读数。若读数是 0.83m，
> 说明真实格长 = 25 × 1.00/0.83 ≈ 30mm，用 `calibrate --square 30` 重解即可
> （不用重新采集图像）；也可以在 `config/calib.yaml` 里什么都不改，
> 直接在 `config/eye_range.yaml` 里按比例修正 `fallback_*`——但推荐重解，避免混淆。

## 5. 现场调试建议

| 现象 | 处理 |
|---|---|
| 目标多时掉帧 | 降 `stereo.threads` 到 4；或提高 `band_max_height`→降低；或把 `num_disparities` 降到 64 |
| 远处目标测不准 | 提高 `num_disparities`（如 192）或提高分辨率；远处视差只有几个像素，误差本来就大 |
| 近处目标测不到 | `num_disparities` 不够大导致超出范围，加大到 192/256 |
| 大量目标显示 `--m` | 场景纹理太弱（白墙）或无标定；先用 `calib-capture/solve` 标定 |
| 界面卡顿 | 降低 `display_scale`（更小）或提高 `display_num_disparities`（但会更慢）；界面刷新与流水线独立，不影响识别 |
| 温度/功耗 | 可通过 `--npu-core 0` 限制单核 NPU，或降低采集帧率 |

## 6. 停止

- 无界面模式：`Ctrl-C`，或 `--duration` 到时自动退出。
- 界面模式：直接关窗口，或 `Ctrl-C`（已支持 SIGINT/SIGTERM 优雅退出）。
- 后台运行后用 `scripts/run_board.sh raw "pkill -f bin/eye_range"` 结束。
